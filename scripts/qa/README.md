# Проверки приложения

Все проверки открывают сайт с локального сервера. Код приложения они не меняют. Сервер запускается в отдельном окне:

```
python -m http.server 8794 --bind 127.0.0.1 --directory site
```

Проверки в браузере лучше запускать по одной. Две сразу нагружают сервер, и страница может не открыться.

| Проверка | Что делает | Время |
|---|---|---|
| `node scripts/qa/test_retrace.js` | «Назад по треку» без браузера. Протока 15 м шириной, поворот каждые 60–80 м, час рыбалки, незаписанный кусок, ошибка GPS телефона. Лодка идёт только по стрелке и должна держаться русла и дойти до слипа. Сравнение со старой стрелкой | 2 с |
| `python scripts/qa/fisher_day.py` | Весь день рыбака: отметил машину, почитал «Сегодня» и «Клёв», «Вести» к точке по протоке (телефон на 40 с блокируется), рыбалка и две метки, «Назад по своему треку» по стрелке со сдвигом с линии, трек сохранён. Записывает всё, что приложение показало и сказало. Снимки: `research/raw/qa/fisher_day/` | 15 мин |
| `python scripts/qa/channel_quiet.py` | Путь туда через протоку в тростнике: навигатор не повторяет «Мелко впереди» и «Поверните левее на 145°» по всей протоке (карты глубин её не знают) и снова подсказывает на открытой воде | 4 мин |
| `python scripts/qa/nav_layout.py` | Кнопки навигатора на 10 экранах (Safari и Chrome, телефон стоя и на боку). Три случая: без плашки, с плашкой, карта сдвинута. Ничто не должно закрывать SOS и текст панели | 3 мин |
| `python scripts/qa/nav_drive.py` | Навигатор в движении: скорость, слежение, палец на карте, щипок, возврат «Ко мне», тёмный экран | 3 мин |
| `python scripts/qa/owner_repro_0926.py` | Жалобы владельца от 26.09: «По месяцам» закрывается (и при сбое), вид маршрута («Авто», «Ко мне», «Путь») | 1 мин |
| `python scripts/qa/shoal_routes.py` | Предупреждения о мелях на пяти маршрутах: не пропускает мель и не кричит зря | 5 мин |
| `python scripts/qa/season_timetravel.py` | Приложение в разные дни года: запреты, лёд, сезон | 2 мин |
| `python scripts/qa/run_qa.py --base http://127.0.0.1:8794/` | Большой набор: 8 устройств, разделы, карточки, листы, навигация, демо, раскладки, клавиши | 30–60 мин |

У каждой проверки код выхода 1, если что-то не так, а в выводе подписано, что именно.

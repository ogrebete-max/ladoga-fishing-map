# Журнал работы приложения

Владелец попросил (24.09.2026): всё, что происходит в приложении на телефонах, должно записываться, чтобы находить и исправлять ошибки.

## Что пишется

`site/log.js` записывает:
- запуск: версию, режим «установлено / в браузере», экран;
- нажатия: код кнопки, без текста полей;
- работу GPS: раз в 5 с в навигации и при записи трека, раз в 30 с в остальное время. Сразу записываются странности: пропуски, плохая точность, скорость телефона не сходится с пройденным путём;
- события навигатора: карта отпущена, возврат, мель впереди, голосовые фразы, «Сторож», «Человек за бортом»;
- ошибки страницы и долгие зависания (Android).

Места округляются примерно до километра. Имён, телефонов и текста полей в журнале нет. В телефоне хранятся последние 1500 событий. На сервер они уходят пачками, когда есть сеть. Отправку можно выключить: «Я → Настройки → Отправлять журнал работы».

«Сообщить о проблеме» (настройки, меню навигации) отправляет слова человека и журнал за последние 40 минут. Если сервер недоступен, телефон предлагает переслать файл в Telegram или почтой.

## Сервер

`ladoga_logs.py` — служба `ladoga-logs.service`. Слушает только 127.0.0.1:8791 и пишет в `/var/lib/ladoga-logs`:
- `YYYY-MM-DD.jsonl` — пачки событий, по строке на пачку;
- `reports/*.json` — сообщения о проблемах;
- `reports.jsonl` — краткий список сообщений.

Файлы старше 60 дней удаляются. IP-адреса не сохраняются. Лимит — 60 запросов в минуту с адреса. Читать журнал можно только по SSH.

Служба ставится и обновляется `scripts/deploy_vps.sh`. Телефоны до неё доходят, только когда у Caddy есть маршрут `/ladoga/api/*`. Это отдельный шаг, потому что веб-сервер общий со «СПб Топливом»: `scripts/logs/enable_caddy_route.sh`. Скрипт проверяет новую настройку до перезагрузки Caddy и после неё проверяет оба сайта. Если что-то не так, прежняя настройка возвращается. Тот же блок нужно добавить в `server/Caddyfile` репозитория spb-fuel-intelligence: его `remote.sh setup` переписывает файл Caddy.

## Посмотреть

```
python scripts/logs/pull_logs.py --days 7
```

Скрипт копирует журнал по SSH в `research/raw/logs/` (в git не попадает) и печатает сводку:
- телефоны и запуски;
- ошибки, сгруппированные по тексту;
- сообщения о проблемах;
- разрешения геопозиции;
- навигатор;
- странности GPS;
- частые нажатия.

# Ладога · рыболовная карта

Интерактивная карта публичных рыболовных геометок южной Ладоги (Волховская губа, Креницы, о. Птинов,
Варецкие банки, о. Сухо, Дубно, Лигово, Вороново, Кобона, Свирская губа): сезоны и перемещения рыбы,
правила рыболовства, происшествия на льду, навигатор «вести к точке», выгрузка GPX для эхолотов и навигаторов.

- Сайт: `site/` (статический, Leaflet), публикуется в GitHub Pages workflow `.github/workflows/pages.yml`.
- Данные: `python scripts/build_data.py` собирает `site/data/*.json` и `site/downloads/*`
  из `data/baseline/` (первое исследование) и `research/*.json` (результаты поиска по источникам, см. `research/BRIEF.md`).

Все точки — из открытых публикаций, у каждой записи есть ссылка на источник. Густота точек показывает,
где чаще публикуют отчёты, а не где больше рыбы.
